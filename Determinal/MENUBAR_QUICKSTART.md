# Determinal Menu Bar Quick Start Guide

## 🚀 Getting Started

When you launch Determinal for the first time, you'll notice:

1. **Dynamic Dock Icon** - Appears when the window is visible, hides when the window is hidden
2. **Terminal Icon** - Look for the terminal icon (▣) in your menu bar at the top of your screen
3. **Floating Window** - The main terminal window appears and stays on top of other windows

## ⌨️ Essential Keyboard Shortcuts

### CMD + Q → **Hide** (App Keeps Running)
```
┌──────────────────────────┐
│   Terminal Window        │
│   [Your work here]       │
│                          │
│   Press: ⌘Q             │
└──────────────────────────┘
                ↓
         Window Hides
                ↓
┌──────────────────────────┐
│  Menu Bar: [▣] ← Ready! │
└──────────────────────────┘
```
**Result**: Window disappears, app stays in menu bar, all data preserved

### Quit (Full Exit)
To fully quit Determinal, use the menu bar icon and select **Quit Determinal**.

### Global Hotkey

#### CMD + SHIFT + ` → **Toggle Window**
```
Working in Safari/Chrome/Any App
              ↓
       Press: ⌘⇧`
              ↓
  Terminal Window Appears!
              ↓
       Press: ⌘⇧` again
              ↓
    Window Hides Again
```
**Works from anywhere** - Switch to Determinal from any application

## 🎯 Common Workflows

### Workflow 1: Quick Query
```
1. Press ⌘⇧` (from anywhere)
   └─> Terminal appears

2. Type: run "explain quantum computing"
   └─> AI processes your query

3. Read the response

4. Press ⌘Q
   └─> Window hides, app stays ready

5. Continue your work
   └─> Determinal ready in menu bar
```

### Workflow 2: Background Task
```
1. Start a long AI inference
   └─> "Analyzing code..."

2. Press ⌘Q to hide
   └─> Processing continues

3. Work in other apps
   └─> Check email, browse, etc.

4. Press ⌘⇧` to check
   └─> See the completed result!
```

### Workflow 3: End of Day
```
1. Finished working?
   └─> Right-click menu bar icon → Quit Determinal

2. App fully quits
   └─> Menu bar icon disappears

3. Next day: Launch Determinal
   └─> Fresh start!
```


## ❓ FAQ

**Q: What happens to my terminal history when I press CMD+Q?**
A: Nothing! All history is preserved. The window just hides.

**Q: Does the app still use resources when hidden?**
A: Minimal! It's idle in the background, using very little memory/CPU.

**Q: Can I disable the menu bar icon?**
A: No—it's essential for accessing the hidden window! Without it, you'd need to re-launch.

**Q: How do I quit the app?**
A: Right-click the menu bar icon and choose "Quit Determinal".

**Q: Does CMD+SHIFT+` work in all apps?**
A: Yes! It's a global hotkey that works system-wide.
