# Determinal Menu Bar Features

## Overview

Determinal lives in your macOS menu bar, providing quick access to your local AI terminal whenever you need it. The app stays running in the background, ready to be summoned at any moment.

## Key Features

### 🎯 Menu Bar Integration

- **Always Available**: Determinal runs as a menu bar application
- **Quick Access**: Click the terminal icon in your menu bar to show/hide the window
- **Background Mode**: App continues running even when window is hidden
- **Dynamic Dock Icon**: Appears when the window is visible and hides when the window is hidden

### ⌨️ Keyboard Shortcuts

#### Window Management
- **⌘ + Q** - Hide the window (app stays running in menu bar)
- **⌘ + ⇧ + `** - Toggle terminal window visibility (works globally)

#### Terminal Commands
- **⌘ + K** - Clear terminal
- **⌘ + I** - Show system status
- **⌘ + M** - List available AI models
- **⌘ + ,** - Open settings
- **⌘ + /** - Show help

### 📍 Menu Bar Actions

Right-click (or left-click) the menu bar icon to access:

1. **Show/Hide Terminal** - Toggle window visibility
2. **Clear Terminal** (⌘K) - Clear terminal output
3. **Show Status** (⌘I) - Display system status
4. **Settings...** (⌘,) - Open settings panel
5. **Documentation** - View command documentation
6. **About Determinal** - App information
7. **Quit Determinal** - Fully quit the application

## Workflow Examples

### Quick AI Query
1. Press **⌘⇧`** from anywhere to show terminal
2. Type your command (e.g., `run "explain this code"`)
3. Press **⌘Q** to hide when done
4. App stays ready in menu bar for next use

### Background Operation
1. Start a long-running AI inference
2. Press **⌘Q** to hide window
3. Continue working in other apps
4. Press **⌘⇧`** to check progress anytime

### Clean Workspace
1. Close window with **⌘Q** when not needed
2. No Dock icon cluttering your workspace
3. Terminal icon in menu bar for quick access
4. Use the menu bar **Quit Determinal** option only when fully quitting

## First-Time Experience

When you first hide the window with **⌘Q**, you'll see a helpful notification:

```
🖥️ Determinal is in your menu bar
Press ⌘⇧` to show again
```

This notification appears once to help you discover the menu bar functionality.

## Tips & Tricks

### Global Hotkey
The **⌘⇧`** shortcut works system-wide, so you can summon Determinal from any application.

### Window Behavior
- Window closes without quitting when you press **⌘Q** or click the close button
- App continues running in background
- Window reopens in same position with all history intact
- Floating window stays on top across all spaces

### Menu Bar Icon
- Click to access quick actions menu
- Icon always visible in menu bar
- Right-click for context menu
- Shows/hides window state

### Full Quit Options
To completely quit Determinal:
1. Choose "Quit Determinal" from the menu bar menu
2. This fully terminates the application

## Settings Integration

The menu bar app integrates seamlessly with Determinal's settings:

- Access settings from menu bar or with **⌘,**
- Settings open in a sheet over the main window
- Changes apply immediately
- Settings persist across sessions

## System Requirements

- macOS 13.0 (Ventura) or later
- Menu bar space for status icon
- Accessibility permissions for global hotkeys (optional)

## Privacy & Performance

- App runs in background with minimal resource usage
- No network connections required
- All processing happens locally
- Menu bar icon uses system resources efficiently
